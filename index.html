How do I create a token?

Scoped to one repo — expires after a year at most:

  1. Open Fine-grained tokens → New token
  2. Repository access → Only select repositories → pick this repo.
  3. Permissions → Repository → Contents → Read and write.

Never expires — paste once per device and forget it, but it can reach all your repos:

  1. Open Tokens (classic) → New token
  2. Expiration → No expiration. Scopes → tick repo.

Either way it never leaves your browser — every request goes straight from this page to api.github.com, and it stays signed in until you sign out.
